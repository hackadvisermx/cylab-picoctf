> 
> *Hints:* "The \"encryption\" algorithm is simple and the correlation between the leakage and the key can be very easily modeled."

## Solución

Al interactuar con el servicio remoto del reto, este solicita un texto en claro de 16 bytes codificado en hexadecimal y responde con una medición de fuga escalar:
```
Please provide 16 bytes of plaintext encoded as hex: 00000000000000000000000000000000
leakage result: 8
```

### Modelo de Fuga
El algoritmo de cifrado evalúa la primera etapa de AES (adición de clave y sustitución no lineal por la S-box estándar):
$$\text{state}_i = \text{Sbox}[P_i \oplus K_i]$$
y reporta la suma del bit menos significativo (LSB) resultante a través de los 16 bytes de estado:
$$\text{leakage}(P) = \sum_{i=0}^{15} (\text{Sbox}[P_i \oplus K_i] \pmod 2)$$

Dado que la función de fuga es una suma aditiva desacoplada por cada byte, podemos atacar cada byte $i \in \{0, \dots, 15\}$ de forma independiente manteniendo todos los demás bytes constantes en cero ($00$):

1. **Línea base:** Se mide la fuga con el vector nulo $P^{(0)} = 00\dots00$:
   $$L_0 = (\text{Sbox}[0 \oplus K_i] \pmod 2) + C_i$$
   donde $C_i = \sum_{j \neq i} (\text{Sbox}[0 \oplus K_j] \pmod 2)$ es constante.

2. **Diferencias escalares:** Para cada byte objetivo $i$, variamos su valor $v \in \{1, \dots, N-1\}$ dejando el resto en cero:
   $$L_v = (\text{Sbox}[v \oplus K_i] \pmod 2) + C_i$$
   Al restar la línea base, la constante $C_i$ se cancela:
   $$\Delta L_v = L_v - L_0 = (\text{Sbox}[v \oplus K_i] \pmod 2) - (\text{Sbox}[0 \oplus K_i] \pmod 2)$$

3. **Unicidad:** La secuencia de diferencias $\{(\text{Sbox}[v \oplus k] \pmod 2) - (\text{Sbox}[0 \oplus k] \pmod 2)\}_{v=1}^{N-1}$ es una huella única para cada una de las 256 hipótesis $k \in [0, 255]$ con tan solo $N = 22$ consultas. Con $N = 25$ consultas por byte, el candidato queda determinado de forma exacta y determinista.

## Notas adicionales
- El vector de ataque no requiere fuerza bruta sobre el espacio de claves de 128 bits ($2^{128}$), sino que desacopla la búsqueda linealmente en $16 \times 25$ consultas debido a la aditividad de la fuga.
- Formato de la bandera: `academy{...}`
