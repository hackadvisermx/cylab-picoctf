# General Skills — ASCII Numbers

## Descripción
> **Prompt oficial:** "Convert the following string of ASCII numbers into a readable string:"
>
> `0x70 0x69 0x63 0x6f 0x43 0x54 0x46 0x7b 0x34 0x35 0x63 0x31 0x31 0x5f 0x6e 0x30 0x5f 0x71 0x75 0x33 0x35 0x37 0x31 0x30 0x6e 0x35 0x5f 0x31 0x6c 0x6c 0x5f 0x74 0x33 0x31 0x31 0x5f 0x79 0x33 0x5f 0x6e 0x30 0x5f 0x6c 0x31 0x33 0x35 0x5f 0x34 0x34 0x35 0x64 0x34 0x31 0x38 0x30 0x7d`
>
> **Hints:**
> 1. CyberChef is a great tool for any encoding but especially ASCII.
> 2. Try CyberChef's 'From Hex' function

- **Categoría:** General Skills
- **Dificultad:** Medium
- **Evento/origen:** (picoCTF, colección General Skills)
- **Autor:** LT 'syreal' Jones

## Solución
Cada número es un byte en hexadecimal (`0x..`) que representa un carácter ASCII. Basta con decodificar cada valor y concatenar:

```bash
python3 -c "
hexes = '0x70 0x69 0x63 0x6f 0x43 0x54 0x46 0x7b 0x34 0x35 0x63 0x31 0x31 0x5f 0x6e 0x30 0x5f 0x71 0x75 0x33 0x35 0x37 0x31 0x30 0x6e 0x35 0x5f 0x31 0x6c 0x6c 0x5f 0x74 0x33 0x31 0x31 0x5f 0x79 0x33 0x5f 0x6e 0x30 0x5f 0x6c 0x31 0x33 0x35 0x5f 0x34 0x34 0x35 0x64 0x34 0x31 0x38 0x30 0x7d'.split()
print(''.join(chr(int(h,16)) for h in hexes))
"
```

## Notas adicionales
- Importante al transcribir strings largas de hex desde una captura/zoom visual del navegador: **usar la extracción de texto del DOM** (`get_page_text` / `read_page`), no leer dígito a dígito de una imagen — un primer intento manual introdujo un error de transcripción (una `0x5f` de más y un `0x6e` perdido) que hizo fallar la primera entrega de la flag.
- CyberChef está disponible en el propio Workspace de CyLab Academy (pestaña junto al Terminal) y también habría servido para esta conversión sin necesidad de Python.
