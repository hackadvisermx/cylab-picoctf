# General Skills — Lets Warm Up

## Descripción
> **Prompt oficial:** "If I told you a word started with 0x70 in hexadecimal, what would it start with in ASCII?"

- **Categoría:** General Skills
- **Dificultad:** Easy
- **Evento/origen:** picoCTF 2019
- **Autor:** Sanjay C/Danny Tunitis

## Solución
`0x70` = `'p'` en ASCII.

Flag: `picoCTF{p}`
